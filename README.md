# Yoda's Tweaks and Fixes

Game restart required after enabling this mod!
Save to add/remove from a save at any time.

## Fixes
*Spirit Animal will now generate Leisure when performing Playing actions and interacting with Disciples. In Vanilla only Playing:Rest would generate Leisure
*Artifact Crafting message will no longer disappear as soon as the Artifact is picked up
*When outers start training they will now look 150 cells away for a Training Dummy (Vanilla: 100 when training as schedule, 10 when training due to "Work Hard")

## Default Features
*Animal Thoughts are now sorted by Type → Level → Name. If an identical shard is already memorized, the shards text will be bold.
*Handworking will now be performed at the same priority as Stonecutting. This should respect the priority setting on the workbench. In Vanilla Stonecutting would always be prefered first.

## Optional Features
Following Features can be toggled in the MLL menu (Esc => MLL设置)

### Outer Disciples Auto Equip Trinkets
If an Outer has Mindful Dresser active (a vanilla toggle in the Disciples equipment page)
They will automatically equip Handkerchiefs and Bells. 
They will also look for useful Talismans such as SpiritTravel, Cleansing, Agility..

### OptIn: Auto Pause on Load

### OptIn: Mentor Guard Disabled
Mentor won't perform the guard action on his disciples when they do a breakthrough.

### OptIn: One Click Interrogate Extended
Almost the same feature as the [original](https://steamcommunity.com/sharedfiles/filedetails/?id=2856326732&searchtext=Interrogate) Mod. 
With the exception that the interrogation will include NPCs known to the player. 
This is useful to find out the favorites of Sect Masters with fewer dialogues.
If you use this mod, you should disable the standalone mod

### OptIn: Brighter Daylight
Days will be brighter, creating a stronger contrast between day and night. 

## Harmony warning 
A warning will be displayed if an outdated Harmony version is used. 
The issue is not cause by this mod, this mod relies on the Harmony version delivered with ModloaderLite. 
This warning is a feature to prevent conflicts which can lead to loss of progress. 
Either disable the mod that provides an outdated harmony version, or delete the harmony file of the conflicting mod manually. 
Mind that steam might download the file again. 
Most commonly this is caused by [SkillLevelInRecruitment](https://steamcommunity.com/sharedfiles/filedetails/?id=2364620535) providing an outdated harmony version. 
I recommend using [Iguanas Overhaul](https://github.com/iguanacore/iguana_acs_functions/) instead.
